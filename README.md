# Chess Analyzer

Расширение для Mozilla Firefox: анализирует шахматную доску на [Chess.com](https://www.chess.com/) и [Lichess.org](https://lichess.org/) локальным движком Stockfish 16 (WebAssembly) и рисует лучший ход зелёной стрелкой поверх доски.

Позиции на внешний сервер не отправляются.

## Возможности

- Распознавание фигур и стороны, которой ходить
- Поиск сильнейшего хода и кратчайшего форсированного мата
- Зелёная SVG-стрелка от клетки хода до клетки назначения
- Автообновление при смене позиции
- Кнопки «Начать анализ» и «Остановить анализ» на странице и в popup
- Оценка позиции (в пешках) и «мат в N»
- Режимы анализа, изучения партий, задач и игры с компьютером на Chess.com и Lichess

## Состав проекта

```
chess-analyzer/
  manifest.json
  engine/stockfish.js
  engine/stockfish-nnue-16-single.wasm
  src/content/          интерфейс на доске
  src/lib/              FEN, чтение доски, стрелки, движок
  src/page/bridge.js    чтение FEN из страницы
  src/popup/            окно расширения
  icons/
```

## Как загрузить в Firefox на Windows 11

1. Установите [Firefox](https://www.mozilla.org/firefox/) (версия 115 или новее).
2. В адресной строке откройте `about:debugging`.
3. Слева выберите **This Firefox** («Этот Firefox»).
4. Нажмите **Load Temporary Add-on** («Загрузить временное дополнение»).
5. Укажите файл `manifest.json` в папке `C:\Users\askib\chess-analyzer`.
6. Откройте, например:
   - https://lichess.org/analysis
   - https://www.chess.com/analysis
7. На панели справа нажмите **Начать анализ**.

Временное дополнение снимается после перезапуска Firefox — после перезапуска повторите шаги 2–5.

Постоянная установка без подписи возможна в Firefox Developer Edition / Nightly (`xpinstall.signatures.required = false`) или через собственную подпись на addons.mozilla.org.

## Использование

1. Откройте анализ, задачу, тренировку или партию с компьютером.
2. Нажмите **Начать анализ**.
3. Дождитесь зелёной стрелки и оценки.
4. Сделайте ход на доске — анализ обновится сам.
5. Нажмите **Остановить анализ**, чтобы убрать стрелку и остановить Stockfish.

Оценка даётся с точки зрения белых: `+0.70` лучше для белых, `-1.20` лучше для чёрных.

## Примечания

- Используется однопоточный Stockfish 16 с классической оценкой (`Use NNUE = false`), чтобы расширение работало без отдельного файла нейросети.
- Если сайт не отдаёт полный FEN, рокировка и взятие на проходе могут быть приблизительными, но фигуры и очередь хода читаются с доски.
- Расширение предназначено для обучения и анализа, а не для скрытой помощи в рейтинговых партиях.
